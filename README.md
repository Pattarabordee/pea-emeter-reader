# PEA E-Meter Reader

Browser-only web app that reads PEA electronic meters over Web Bluetooth.

- `npm run dev` - dev server
- `npm test` - Vitest
- `npm run build` - production build to `dist/` (base `/pea-emeter-reader/`)

Deployed to GitHub Pages by `.github/workflows/pages.yml`. Requires Node 20+ to build.
